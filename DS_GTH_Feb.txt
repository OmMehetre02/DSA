Q. What are two pointer approaches?
________________________________________________________________________
 Two pointer approach means we operate two index at time on array at the time of iteration either both index move or either any one index move called as two pointer and the benefit of two pointer approach is improve the complexity or minimize the complexity of code and almost sorting algorithm work with two pointer approach 


Example with source code 
public class RevArr
{  public static void main(String x[])
   {    int a[]=new int[]{10,20,30,40,50};
	  int i,j;
	  System.out.println("Before reverse array");
	  for(i=0; i<a.length; i++)
	  { System.out.printf("%d\t",a[i]);
	  }
	  int left=0;
	  int right=(a.length-1);
	  while(left<right)
	  {     int temp=a[left];
			a[left]=a[right];
			a[right]=temp;
			left++;
			right--;
	  }
	  System.out.println("\nAfter reverse array\n");
	  for(i=0; i<a.length; i++)
	  { System.out.printf("%d\t",a[i]);
	  }
   }
}

 Linear and Binary Search Algorithm
 _______________________________________________________________________

Linear Search: Linear Search can work with sorted as well as unsorted array and in linear search we compare search with every element in array and if we found search we break the loop and catch or find the index of search value and if search key not found return -1

Algorithm of linear search 
Start 
Store data in array 
Input search key 
Set index=-1 or any variable with -1 value 
Compare search key with every element in array from  0 to n-1
If search key match with any element in array then set index=i 
And break loop
Compare index with -1 outside of loop if  index not minus -1 then announce value found otherwise announce value not found 
Stop

Binary Search 
_______________________________________________________________
Binary Search algorithm only works with sorted data or on sorted array 
So the rule of binary search is divide the array in two parts and find out the mid value 
Compare search key with mid value if search key match with mid value then we stop searching 
If search key is greater than mid then we search data at right hand side of array again divide array in two parts find mid value repeat process and if search is less than mid value then search value at left hand side of array and repeat process mention above 

Example with source code 
________________________________________________________________________
import java.util.*;
public class BSAPP
{  public static void main(String x[])
   {  int a[]= new int[10];
	 Scanner xyz  = new Scanner(System.in);
	 System.out.println("Enter values in array");
	 for(int i=0; i<a.length; i++)
	 { a[i]=xyz.nextInt();
	 }
	 System.out.println("Enter search key");
	 int skey=xyz.nextInt();
	 int index=-1;
	 int L=0,R=(a.length-1);
	 while(L<R)
	 {  
	    int mid=L+(R-L)/2;
		if(a[mid] == skey)
		{  index=mid;
		   break;
		}
		if(a[mid]<skey)
		{ L=  mid+1;
		} 
		else{
		  R= mid-1;
		}
	 }
	 if(index!=-1)
	 { System.out.println("Value found");
	 }
	 else{
	   System.out.println("Value not found");
	 }
   }
}

Bubble sort algorithm
__________________________________________________________________
Bubble sort algorithm is a simple comparison based sorting algorithm that repetitively steps through the list , comparing adjacent elements and swapping them if they are unsorted.

import java.util.*;

    public static void main(String x[])

		   }

   static int front=-1,rear=-1;
   public static void main(String x[])

     do{

	   {
	      case 1:
		  System.out.println("Enter value in queue");
		  int value=xyz.nextInt();
		  insert(value);
		  break;
		  case 2:
		  delete();
		  break;
		  case 3:
		  display();
		  break;
		  case 4:
		   System.exit(0);
		   break;
		  default:
		  System.out.println("Wrong choice");
	   }
	 }while(true);
   }
   public static void insert(int value)
   {
       if(((rear+1)%q.length)==front)
	   { System.out.println("Queue is full");
	   }
	  
	   else{
      if(front==-1)
	   { front=0;
	   }
	     rear=(rear+1)%q.length;
		 System.out.println("Rear is "+rear);
		 q[rear]=value;
		 System.out.println("Data inserted");
	   }
   }
     public static void delete()
   {
        if(front==-1)
		{ System.out.println("Queue is underflow or empty");
		}
		else{
		   int value=q[front];
		   System.out.println("Delete value is "+value);
		   if(front==rear)
		   { System.out.println("Queue is empty");
		     front=rear=-1;
		   }
		   else{
		     front=(front+1)%q.length;
			 
		   }
		}
   }
   
   public static void display()

   if(front==-1)
   { System.out.println("Queue is empty");
   }
   else{
      int i=front;
	  while(true)
	  {
		System.out.printf("%d\t",q[i]);

		 }
		 i=(i+1)%q.length;

String is an immutable class in Java where we can say immutable  means once we initialize a value we cannot change later called as immutable.
There are two ways to create string objects 
_____________________________________________________________________
Using an initialization 
Example: String str=”abc”;
Using a new keyword

Q. What is the difference between String creation using a new keyword and using initialization technique?
_______________________________________________________________________
When we create string using a initialization technique then string create in a string constant pool and when we create string using a new keyword then string create heap section of memory 
When we create string using a initialization technique and if we string has a same data then internally JVM create only one string object in memory and store that address in different reference variable and if we use new keyword for string creation and if we have same string object then JVM create new two different object of strings
